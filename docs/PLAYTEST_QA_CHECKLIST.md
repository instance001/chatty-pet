# Playtest QA Checklist

Use this checklist before release-signing and store submission work. Run it from a fresh save on a real phone if possible.

## First-Run Flow

- [ ] Launch from a fresh install or cleared save.
- [ ] Splash feels clean and not too slow.
- [ ] First screen explains itself without outside context.
- [ ] New player can figure out: place item, select item, step time, use item.
- [ ] No confusing moment appears in the first 60 seconds.

## Core Care Loop

- [ ] Feeding Chatty feels clear and satisfying.
- [ ] Playing with Chatty feels clear and satisfying.
- [ ] Rest items feel useful and understandable.
- [ ] Clean items feel useful and understandable.
- [ ] Mood changes feel noticeable and fair.
- [ ] "What To Try Next" guidance usually matches the right next action.

## Progression

- [ ] First unlock arrives quickly enough to feel rewarding.
- [ ] Unlock feedback is visible and satisfying.
- [ ] At least two unlock tiers feel reachable in normal play.
- [ ] Progression does not feel too slow or too shallow.
- [ ] Newly unlocked items feel meaningfully different from starter items.

## Clarity And Friction

- [ ] The app explains impossible actions plainly.
- [ ] Selected-item guidance makes the next step obvious.
- [ ] Inspect/use buttons feel intuitive when items are or are not ready.
- [ ] Status panel feels helpful rather than noisy.
- [ ] No repeated action pattern feels annoying in the first 10-15 minutes.

## Content Variety

- [ ] Lines do not repeat too quickly.
- [ ] Each item category has a distinct feel.
- [ ] No unlock feels empty or redundant.
- [ ] The toy box feels broad enough to support repeat visits.
- [ ] Chatty still feels charming after multiple loops.

## Persistence And Reset

- [ ] Closing and reopening restores current progress correctly.
- [ ] Save restore preserves needs, items, unlocks, and current state cleanly.
- [ ] Reset warning is clear before progress is wiped.
- [ ] Reset fully clears local progress and starts fresh.

## Phone Readability

- [ ] Portrait layout is readable and comfortable.
- [ ] Buttons are large enough to tap reliably.
- [ ] Speech bubble text wraps cleanly.
- [ ] Guidance cards and support sheets read clearly on a phone.
- [ ] Care shelf still feels usable after more items unlock.

## Support And Trust

- [ ] Help text matches the real gameplay loop.
- [ ] Privacy text matches the real local-only behavior.
- [ ] About text and app identity feel ready for public release.
- [ ] No screen implies accounts, ads, analytics, or cloud dependence.

## Release Decision

Answer these before proceeding:

- [ ] A kid or parent can understand what to do without developer explanation.
- [ ] The app feels charming in the first five minutes.
- [ ] The app feels like a complete small toy, not a placeholder.
- [ ] Repeat visits feel pleasant rather than obligatory.
- [ ] No remaining confusion or frustration is serious enough to block release.
