# Roadmap

## Current Focus

Stabilize the Android-ready toy build so the app is understandable, testable, and honest before pushing harder on release mechanics.

## v0.1

Deterministic pet skeleton with reducer-owned truth, one room, one pet, starter items, support surfaces, and basic interactions.

## v0.2

Improve toy completeness:

- clearer item feedback
- stronger first-time onboarding
- light usability polish
- optional tiny goals or mood loop improvements

## v0.3

Separate starter content more cleanly and move toward external datapack-style definitions.

## v0.4

Custom item creator so users can add honest new templates.

## v0.5

Local save and load.

## v0.6

Optional narration polish and richer assets without letting decoration own truth.

## v1.0

Google Play candidate with:

- stable Android packaging
- real release signing
- privacy/help/about surfaces in good shape
- screenshots and store metadata
- repo docs aligned with the shipped app
